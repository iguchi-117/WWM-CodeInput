# WWM コード高速入力ツール

ゲーム内コード入力ページ（ブラウザ等）に、WWM（Where Winds Meet / 燕雲十六声）の引き換えコードを**爆速で連続入力**するためのデスクトップアプリ。

## ✨ 特徴

- ✅ **ホットキー操作** — マウスに触らず連続でコード入力
- ✅ **JSON外部管理** — コードは `codes.json` で一元管理。エディタで直接編集OK
- ✅ **新規コード即対応** — アプリ起動中に `codes.json` を編集 → 5秒以内に自動再読込
- ✅ **使用済自動マーク** — 一度入力したコードはグレーアウト、二度と出ない
- ✅ **追加インストール不要** — 配布exe版は Python 不要
- ✅ **yar.gg 連携** — 「🌐 yar.gg を開く」でサイトをブラウザ起動、コピーしたコードを一括追加

## 🌐 yar.gg からコードを追加する

> ℹ️ **コードの取得は2通り。** 推奨はツールバーの「⤓ yar.gg 自動取得」
> （公開API `https://codes.yar.gg/api/codes` から一括取得・重複スキップ・失効マーク）。
> 目視確認しながら拾いたい場合は「🌐 yar.gg を開く」→「＋ 一括追加」の手動導線も残している。

手動で追加する手順：

1. ツールバーの **「⤓ yar.gg 自動取得」** をクリック → 公開APIから一括取得（推奨）
2. またはツールバーの **「🌐 yar.gg を開く」** をクリック → ブラウザで `https://codes.yar.gg` が開く
3. ページのコードをコピー（複数行まとめてコピー可）
4. **「＋ 一括追加」** をクリック → **「📋 クリップボードから」** で貼り付け
5. プレビューで「除外」件数を確認し、「追加」

`codes.json` との重複は自動スキップされます。

### 方法 A: 配布exe版（推奨・簡単）

`dist/WWMCodeInput.exe` をダブルクリック。

```bash
start.bat
```

```bash
python app.py
```

## ⌨️ ホットキー一覧

### アプリ内（フォーカスがウィンドウにある時）
| キー | 動作 |
|------|------|
| `Ctrl+C` | 選択行のコードをクリップボードにコピー |
| `Alt+G` | **次の未使用コード**を自動コピー（メイン操作） |
| `Ctrl+Shift+U` | 選択中のコードを全部「使用済」にマーク |
| `Delete` | 選択行を使用済にマーク |
| `Insert` | 新規コード一括追加ダイアログ |
| `F5` | codes.json を再読込 |
| `Ctrl+,` | 設定ダイアログ（ホットキー変更など） |

### グローバル（ゲームにフォーカスがあっても効く）
| キー | 動作 |
|------|------|
| `Alt+G` | **次の未使用コード**をクリップボードにコピー（デフォルト） |
| `Alt+Shift+G` | コピー + 自動ペースト（合成 `Ctrl+V` を送信。設定で ON/OFF・遅延変更可） |

> ⚠ 実測: ゲームクライアントは合成 `Ctrl+V` を吸収する（メモ帳対照では成功）ため、**ゲーム内の貼付は手動 `Ctrl+V`** が正規。

> 💡 **推奨ワークフロー**:
> 1. アプリ起動 → `Alt+G` で1件目をコピー
> 2. ゲームにフォーカス → コード入力欄に `Ctrl+V`
> 3. **入力成功** → ゲームからアプリに戻らず `Alt+G` で次のコードがコピーされる
> 4. そのままゲームにフォーカス → `Ctrl+V` で2件目…
>
> このサイクルなら**5秒/1コード**で連続入力できます。

## ⚠ ゲーム中 (DirectX フルスクリーン) で動作させるには

**管理者権限で起動** する必要があります。一部のアンチチートソフトや DirectX の
フルスクリーン排他モードは、`pynput` の `WH_KEYBOARD_LL` キーボードフックを
ブロックするためです。

### 設定手順

1. **デスクトップの「WWM Code Input」ショートカットを右クリック**
2. **「プロパティ」** を開く
3. **「ショートカット」タブ** → **「詳細設定(V)...」**
4. **「管理者として実行(R)」** にチェック → **OK**
5. **「適用(A)」** → **「OK」**

これでショートカットをダブルクリックすると UAC ダイアログが出ます。
「はい」を押せば管理者権限で起動し、ゲーム中でもホットキーが効きます。

> 💡 設定後はショートカットに **盾マーク (管理者アイコン)** がつきます。

```json
      "used_at": null,

    }
  ]
```

### 新規コードを追加する方法（3通り）

#### A. アプリ内で追加（推奨）
1. アプリ起動中に `Insert` キー（または「＋ 追加」ボタン）
2. ダイアログにコード入力 → Enter
3. 自動的に `codes.json` に追記 + UI に反映

#### B. ファイルを直接編集
`codes.json` の `codes` 配列末尾に新しいオブジェクトを追加：

```json
{
  "code": "NEWCODE123",
  "used": false,
  "added_at": "2026-07-02",
  "used_at": null,
  "source": "手動追加"
}
```

アプリを起動していれば 5秒以内に自動反映。起動していなければ次に起動した時。

#### C. スクリプトから追加
```python
import json
with open("codes.json", encoding="utf-8") as f:
    data = json.load(f)
data["codes"].append({
    "code": "NEWCODE123", "used": False,
    "added_at": "2026-07-02", "used_at": None, "source": "スクリプト"
})
with open("codes.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)
```

## 🛠 機能詳細

### ペースト後の自動「次へ」コピーについて

**技術的制約**: `Ctrl+V` はクリップボードを変更しない（読むだけ）ため、「ペーストした瞬間」を純粋に検知するのは不可能です。

**本アプリの解決策**:
1. **メイン方式**: グローバルホットキー `Alt+G`（ゲームにフォーカス中でも効く）で次の未使用コードをコピー
   - 「ペースト終わった」→「`Alt+G`押す」→ 次のコードがクリップボードに入る
2. **自動ペースト併用**: `Alt+Shift+G` でコピー + 合成 `Ctrl+V`（設定で ON/OFF・遅延変更可）
   - 実測: ゲームクライアントは合成 `Ctrl+V` を吸収するため、ゲーム内の貼付は手動 `Ctrl+V` が正規
3. **補助方式**: アプリにフォーカスが戻ったとき（Alt+Tab）にステータスバーで「次へコピーできます」と通知
4. **マーク**: 固定ホットキー `Ctrl+Shift+U` で選択中のコードを一括使用済

これにより「**5秒で1コード**」の高速入力サイクルを実現しています。

### アトミック書き込み
- `codes.json.tmp` に書いてから `os.replace()` でリネーム
- 書き込み中にクラッシュしても既存ファイルは無傷
- 毎回 `.backup.json` も自動生成

### 重複防止
- 同じコード（大文字小文字区別なし）が既にあれば追加ダイアログで警告
- `codes.json` を直接編集した場合も、起動時にチェック

### 🖥 デスクトップ支援CLI (auto_redeem.py)

手動フロー（Alt+G → 人間 Ctrl+V）の補助ツール。codes.json への保存経路は持たない。

```bash
python auto_redeem.py --list-windows                 # 可視ウィンドウ一覧 + ゲーム検出
python auto_redeem.py --dry-run --limit 3            # 次の未使用コードを表示 (保存なし)
python auto_redeem.py --once                         # 1件貼付テスト (要ゲーム起動・保存なし)
python auto_redeem.py --shot shot.png --crop center  # 確定直後キャプチャ
```

- 実デスクトップ操作が前提。ゲーム排他全画面では Alt+Tab で戻して使用

### 外部ファイル変更の自動検知
- 5秒ごとに `codes.json` の mtime を確認
- 変更があれば自動再読込 → Treeview 更新

### exe 化での `codes.json` 取り扱い
- `codes.json` / `settings.json` は exe に同梱しない（`--add-data` なし）。ユーザーデータは exe の外に置く
- データフォルダは `WWM_DEV_DATA_DIR` → exe（`sys.executable`）と同じフォルダ の順に解決（`start.bat` は開発元フォルダを指定）
- `codes.json` の参照先は 環境変数 `WWM_CODES_JSON` > 設定の「参照先」> データフォルダ の順（設定変更は再起動で反映）
- 初回起動時に `codes.json` が存在しなければ空のものを自動生成
- 既存 `codes.json` を編集する場合は実際の参照先を開く（設定ダイアログに現在の参照先を表示）

## 🐛 トラブルシューティング

### 「⚠ グローバルホットキー Ctrl+G の登録に失敗しました」と表示される
- 他のアプリが `Ctrl+G` をグローバルホットキーとして使っている可能性
- 代替: アプリ内で `Ctrl+G` を使う（フォーカスをアプリに戻して操作）

### クリップボードへのコピーが動かない
- 一部リモートデスクトップ環境では `OpenClipboard` が失敗する場合あり
- その場合は「＋ 追加」ダイアログでコードを追加後、ダブルクリックで再試行

### exe版で codes.json が読み込まれない
- セキュリティソフトが `_MEIPASS` 展開をブロックしている可能性
- exe と同じフォルダに手動で `codes.json` を配置してください

### Windows Defender が exe をブロック
- 「詳細情報」→「実行」で起動可能
- 配布時は VirusTotal 等でチェック推奨

### アプリが起動しない（Python版）
- Python 3.11+ をインストール: https://www.python.org/downloads/
- インストール時に **"Add Python to PATH"** にチェック
- コマンドプロンプトで `python --version` で確認
